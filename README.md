# CircuitBreaker

Cloud-Native E-Commerce API Gateway using Spring Cloud, Eureka and Resilience4j.

## Modules
- Product Service
- Inventory Service
- Recommendation Service
- Service Registry (Eureka)
- API Gateway

## Planned Resilience Patterns
- Circuit Breaker
- Retry
- Timeout
- Bulkhead
- Rate Limiter

## Project Goal
Prevent cascading failures in a cloud-native e-commerce microservices architecture.
